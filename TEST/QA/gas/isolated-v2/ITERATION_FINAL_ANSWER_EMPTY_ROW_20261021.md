# ROUTEQ｜最終回答保存の空行拒否・再検査（2026-10-21）

## 検出した問題
`回答確認.gs:saveFinalAnswer()` では確認対象の行番号が有効でも、Questionsの質問本文が空の行に最終回答を保存できる可能性があった。

## 修正
`Questions` の行番号と上限を検証した後、質問本文列（`ROUTE_QA.QUESTION_COL.QUESTION`）の値が空白でないことを確認し、空行なら警告して保存せずに終了するよう変更した。GitHub隔離TESTブランチのみ変更。原本・main・実環境無変更。

## モック検収
保存済みコードから `saveFinalAnswer()` を取り出して実行し、Google Sheets・UIはメモリモックで再現：
1. 質問が存在する行の最終回答・確認状態・更新時刻の保存→PASS
2. 既存範囲内で質問本文が空の行への保存拒否→PASS
3. 範囲外の質問行への保存拒否→PASS
4. 小数の質問行への保存拒否→PASS
5. 最終回答が空のときの保存拒否→PASS

5件／5件PASS。修正済みGS全体のJS構文PASS。GitHub保存後の再取得一致PASS。
