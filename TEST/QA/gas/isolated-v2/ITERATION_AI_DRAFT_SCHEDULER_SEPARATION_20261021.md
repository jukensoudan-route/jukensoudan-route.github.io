# ROUTEQ｜AI回答生成と返信予約の失敗分離（2026-10-21）

## 不具合
`saveQuestionForWeb_` のAI回答生成処理では、AI回答を Questions に「生成済」として保存した直後、`autoSendRouteAnswerIfEnabled_` が失敗すると同じcatchがAI生成失敗として処理し、完成したAI回答を「【生成エラー】...」で上書きする。TESTの遅延返信予約は強制停止のため、この現象が起きやすい。

## 修正
AI回答保存・生成成功を確定した後、返信予約だけを独立のtry/catchで実行し、予約失敗は記録するが、生成済AI回答を上書きしない。送信状態は無断で「送信済」に変更しない。TESTブランチ`isolated-v2/訂正シート最優先・直接参照.gs`のみ変更した。

## 実コード抽出＋モック検収
1. AI回答成功＋返信予約失敗：AI「生成済」・回答本文維持、予約失敗はログ記録 → PASS
2. AI回答成功＋返信予約成功：AI「生成済」維持 → PASS
3. AI回答生成自体の失敗：AI「エラー」、理由を回答欄に記録 → PASS

3/3 PASS。更新後構文検査、GitHub保存後再取得照合PASS。スプレッドシート・GAS・LINE・決済の実操作なし。
